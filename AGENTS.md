# AGENTS.md — Конституция проекта

Локальный бизнес в Йошкар-Оле. Премиальные продукты питания: морепродукты и экзотические фрукты. Доставка по городу, пункт выдачи, оплата онлайн.

## 1. General Principles

- Единый файл `index.html` со встроенным стилем через Tailwind CSS (CDN)
- Google Fonts: Playfair Display (заголовки) + Inter (основной текст)
- JavaScript — не используется
- Placeholder-изображения с Unsplash, позже заменяются на свои фото

## 2. Project Structure

```
Magazine/
├── index.html          — главная (и единственная) страница
├── photos/             — изображения продукции (свои)
├── AGENTS.md           — этот файл
```

## 3. Code Standards

### HTML
- Семантическая разметка: `<header>`, `<main>`, `<section>`, `<footer>`
- Атрибут `alt` у всех `<img>` — осмысленное описание
- ARIA-атрибуты для интерактивных элементов
- Tailwind CSS подключается через CDN (`<script src="https://cdn.tailwindcss.com">`)
- Конфигурация Tailwind — во встроенном `<script>` с `tailwind.config`
- Пользовательские стили — в `<style>` (минимально: фон Hero, glassmorphism)

### CSS
- Все стили через Tailwind utility-классы в HTML
- Кастомные CSS-классы только если Tailwind не покрывает (анимации, фоновые изображения)
- BEM не используется — стилизация через Tailwind

### Naming Convention
- Классы Tailwind: `bg-slate-900`, `text-white`, `rounded-2xl` и т.д.
- Кастомные классы: `card-glass`, `hero-bg` (только для сложных стилей)

## 4. Design Requirements

- **Mobile-first**: Tailwind `sm:`, `md:`, `lg:` breakpoints
- **Breakpoints**: sm (640px), md (768px), lg (1024px), xl (1280px)
- **Контрастность**: минимум 4.5:1 для обычного текста
- **Стиль**: Premium Dark — глубокий тёмный фон, glassmorphism-карточки, белые заголовки
- **Шрифты**: Playfair Display (заголовки), Inter (текст)
- **Touch targets**: минимум 44×44px для кнопок и ссылок
- **Адаптивность**: проверять на 375px (mobile), 768px (tablet), 1024px+ (desktop)

## 5. Performance

- Tailwind CDN (подходит для лендинга, продакшн — Tailwind CLI)
- Ленивая загрузка изображений: `loading="lazy"` у всех `<img>` кроме Hero
- Изображения: `width` и `height` атрибуты всегда (защита от CLS)
- Шрифты: `display=swap` для Google Fonts

## 6. AI Working Rules

1. **Перед созданием файла** — объясни, зачем он нужен и что в нём будет
2. **После написания кода** — предложи способ проверки (открыть в браузере)
3. **При предложениях изменений** — поясни, почему это нужно и что улучшит
4. **Не добавляй комментарии в код** без явной просьбы пользователя
5. **Следи за единообразием** — новые блоки пиши в стиле уже существующих
6. **При сомнениях** — спроси, а не додумывай за пользователя

## 7. Brand

- **Название**: Магазин (временное)
- **Город**: Йошкар-Ола, Республика Марий Эл
- **Тон**: тёплый премиум, обращение на «ты», без снобизма
- **Продукция**: морепродукты (форель, красная икра), экзотические фрукты
- **Модель продаж**: сайт презентует → клиент переходит в Telegram → заказывает и оплачивает
- **Цены**: на сайте не показываются, актуальные — в Telegram-канале Макса
